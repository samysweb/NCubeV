Analysis

Utilities for processing constraints and pre-processing queries before decomposition.

API

NCubeV.Analysis — Module

Analysis

Preprocessing and constraint analysis utilities: variable mapping, fixing variables, translating atoms into linear/semi-linear constraints, and building over-/under-approximations used by Mosaic.

source
NCubeV.Analysis.fix_variables — Method
fix_variables(f::Formula, mapping::Dict{String, Union{String, Number}})

Substitute variables in f using either numeric constants or inline formulas provided as strings. The latter are parsed via Parsing.parse_term.

source
NCubeV.Analysis.get_overapprox — Method
get_overapprox(f)

Construct the structural over-approximation of a formula, pushing the modality through connectives.

source
NCubeV.Analysis.get_underapprox — Method
get_underapprox(f)

Construct the structural under-approximation of a formula, dual to get_overapprox.

source
NCubeV.Analysis.make_linear — Method
make_linear(left, right, comp, var_number) -> Union{LinearConstraint, Formula}

Build a linear or semi-linear constraint from an atom left comp right, moving everything to the left-hand side. Returns a conjunction/disjunction for Eq/Neq.

source
NCubeV.Analysis.translate_constraints — Method
translate_constraints(f::Formula, variable_set::Set{Variable})

Translate linear atoms to LinearConstraint/SemiLinearConstraint using the current number of variables. Nonlinear atoms are left untouched.

source
NCubeV.Analysis.translate_constraints_internal — Method
translate_constraints_internal(var_number)

Return a rewriter function that applies make_linear to linear atoms.
